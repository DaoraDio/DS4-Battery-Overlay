# Changelog

## Unreleased

- Windows startup launches quietly in the tray; manual launches still open settings. Existing startup entries for the same executable are updated automatically.
- Added common-problem troubleshooting and clarified that MSI Afterburner is optional; only RTSS is required for the in-game battery overlay.

## 1.0 — Version 1

Initial public release of DS4 Battery Overlay.

- RTSS battery artwork with configurable position, size, colors, fill style and percentage placement.
- Desktop widget with separate appearance, drag positioning and optional click-through.
- Connection, battery and charging notifications, trigger selection, duration and delayed tests.
- Optional fixed or battery-based lightbar colors and brightness.
- Persistent, filterable event history with text export.
- Live tray battery icon, optional Windows startup and Bluetooth controller power-off.
- RTSS client plugin with separate Toggle / Show / Hide shortcuts for PC statistics.
- In-app setup guide and plugin installation with backups.
